# CBOT 农产品 · 卖Put/卖Call 理论价位带面板

一个**每日自动更新**的公开面板，跟踪 CBOT 四大农产品期权（大豆 ZS / 豆粕 ZM / 玉米 ZC / 豆油 ZL）
产业卖权收租**理论上**最密集的虚值价位带。

> 在线地址（GitHub Pages 自动发布后填写）：`https://<你的用户名>.github.io/<仓库名>/`

---

## 这个面板到底给了什么（诚实声明）

面板只有**三列**：

| 列 | 含义 | 数据性质 |
|---|---|---|
| 支撑线 · 真实期货价 | 新浪财经连续主力真实报价 | ✅ **真实** |
| 卖Put上沿（价格下方 Δ≈0.25） | 最靠近平值的 OTM Put 收租边界 | 🟡 **推算**（真实价 + 假设IV 经 Black-76） |
| 卖Call下沿（价格上方 Δ≈0.25） | 最靠近平值的 OTM Call 收租边界 | 🟡 **推算** |

- **期货价是真的**（新浪免费公开，每日抓取）。
- **价位带是数学模型算出来的位置**，不是"哪个价位 OI 最集中"——
  后者必须依赖真实的逐档持仓量（QuikStrike / CME 导出），免费源给不到买卖方向。
- IV 用的是近一年历史波动率近似（大豆22% / 豆粕28% / 玉米25% / 豆油30%），带会随 IV、到期日变化而平移。

换句话说：它回答"卖权收租**理论上落在哪**"，不回答"**哪个价位最拥挤**"。
后者是另一个面板（`dashboard.html`，需真实 OI 投喂，详见下文）。

## 自动更新机制

- 通过 GitHub Actions 每日 **15:45 北京时间（07:45 UTC）** 自动运行；也可在 Actions 页手动触发。
- 工作流：抓取新浪真实价 → Black-76 推算三列带 → 发布到 GitHub Pages。
- 若某日新浪在 runner 上不可达，工作流会**沿用上次已发布的版本**继续服务，不会出现空白页。

## 本地运行（在你自己的机器上，可拿到更全的数据）

```bash
cd cbot_put_dashboard
python daily.py          # 始终产出 real_band.html（三列理论带）
python fetch_barchart.py # 尽力拉 Barchart 免费逐档 OI -> data/incoming/cbot_options_<date>.csv
```

- `real_band.html`：三列理论带（真实价 + 推算），**零付费、零账号**。
- `dashboard.html`：真实逐档 OI 集中度（5 步打分）。需要 Barchart 免费源可达，
  或你手动把 QuikStrike / Barchart 导出的逐档 OI CSV 放进 `data/incoming/` 后重跑 `python pipeline.py`。
  ⚠️ "卖Put集中"是**对高虚值 Put 高 OI 堆的概率推断**，非确定性事实（免费源不分买卖方向）。

## 数据来源与限制

| 源 | 用途 | 限制 |
|---|---|---|
| 新浪财经 `hq.sinajs.cn` | 真实连续主力期货价 | 免费公开；国际网络偶尔不稳 |
| Barchart 免费期权页 | 逐档总 Put OI / Delta / IV（延迟、无方向） | 反爬严格，沙箱/部分网络被挡 |
| QuikStrike / CME 导出 | 真实 OI-by-strike（含方向） | 付费/需账号，本仓库不内置 |
